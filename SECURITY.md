# 보안 정책 / Security Policy

## 지원 버전 / Supported Versions
현재는 `main` 브랜치의 최신 커밋만 지원합니다.
Only the latest commit on `main` is supported.

## 취약점 제보 / Reporting a Vulnerability
**공개 Issue로 올리지 마세요.** 저장소의 **Security → Report a vulnerability**(비공개 취약점 제보)를 이용해 주세요.
**Please do not open a public issue.** Use **Security → Report a vulnerability** (private vulnerability reporting) on this repository.

다음 내용을 포함해 주시면 도움이 됩니다 / Please include:
- 영향받는 파일·버전 / affected file and version
- 재현 방법 / steps to reproduce
- 예상되는 영향 / potential impact

확인 후 가능한 한 빨리 답변드리겠습니다. 개인 프로젝트이므로 응답이 늦어질 수 있습니다.
This is a personal project; responses are best-effort.

## 범위 / Scope
- 이 저장소의 코드와 설정(GitHub Actions 포함) / Code and configuration in this repository, including GitHub Actions
- 의존성 자체의 취약점은 해당 프로젝트에 먼저 제보해 주세요 / Report vulnerabilities in dependencies to their upstream projects first

## 알려진 사항 / Known Issues
의존성의 알려진 취약점과 영향 분석은 `docs/security-notes.md`에 기록합니다.
Known dependency vulnerabilities and their impact analysis are tracked in `docs/security-notes.md`.
